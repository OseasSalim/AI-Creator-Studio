# AI Creator Studio — Documento mestre

O AI Creator Studio é uma plataforma SaaS para transformar ideias em roteiros, personagens, cenas e conteúdos para redes sociais.

## Estado atual

A Etapa 01 — Fundação foi implementada. A Etapa 02 está em progresso: a integração e as migrações foram preparadas, mas a validação final depende de um projeto Supabase configurado.

## Stack

React + Vite + TypeScript, Tailwind CSS, Lucide React, React Router, Node.js + Fastify, npm workspaces e pacote compartilhado de contratos.
